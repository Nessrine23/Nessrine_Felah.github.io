NutriSmart

Intelligent Nutrition Platform

🌱 Project Overview

NutriSmart is an intelligent nutrition platform designed to help users adopt a healthier lifestyle.

The platform combines nutrition services, geolocation and personalized recommendations to help users discover healthy restaurants and gyms.

🎯 Project Objectives

  • Help users discover healthy restaurants.
  • Recommend gyms according to the user's location.
  • Provide an interactive geolocation experience.
  • Facilitate access to healthy lifestyle services.

🛠️ Technologies

Symfony · PHP · MySQL · JavaScript · Leaflet

👩‍💻 My Contribution

This project allowed me to work on web development, database management, geolocation services and the integration of interactive maps.
