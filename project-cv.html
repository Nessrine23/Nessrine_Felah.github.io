CV Analysis & Job Matching System

An intelligent NLP-based system designed to automatically analyze CVs, classify candidate profiles and recommend relevant job opportunities.

Project Overview

This project aims to automate part of the recruitment process using Natural Language Processing and Machine Learning techniques. The system analyzes the content of a candidate's CV and extracts relevant information to identify the candidate's professional profile and match it with suitable job opportunities.

Objectives

  • Automatically analyze CV documents.
  • Classify candidates according to their profiles.
  • Extract relevant skills and information.
  • Recommend suitable job opportunities.
  • Reduce the time required for manual CV screening.

Technologies

Python NLP Machine Learning Transformers RoBERTa Streamlit

Approach

The system follows several steps:

  1. CV data collection and preprocessing.
  2. Text cleaning and normalization.
  3. Tokenization and NLP processing.
  4. Feature extraction and text representation.
  5. Machine Learning / Transformer-based classification.
  6. Job recommendation based on the candidate profile.

Results

The project achieved promising results for automatic CV classification and demonstrated the potential of NLP and Transformer models for intelligent recruitment systems.
