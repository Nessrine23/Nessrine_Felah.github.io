🌍 1. The Project

TalentSphere is an intelligent recruitment platform created to digitalize and optimize the complete recruitment cycle.

The platform combines Artificial Intelligence, Natural Language Processing, Computer Vision, Speech Analysis and Machine Learning to provide intelligent tools for both candidates and recruiters.

👤 Candidate Space

  • CV upload and analysis
  • AI-powered interview simulation
  • Skills assessment quizzes
  • Intelligent job recommendations
  • Personalized feedback

🏢 Recruiter Space

  • Automated candidate matching
  • Candidate evaluation
  • Video interview analysis
  • Behavioral analysis
  • Automatic PDF report generation

🎯 2. My Role

Lead — CV Analysis & Guidance Module

Within a team of six Data Scientists and Developers, I was responsible for the design, development and deployment of the CV Analysis & Guidance Module.

The objective was to create an intelligent system capable of understanding the semantic structure of a CV, identifying strengths and weaknesses and generating personalized recommendations.

💡 My Technical Approach

  1. Data Preparation

    Processing of the UpdatedResumeDataSet dataset from Kaggle using an NLP preprocessing pipeline, including cleaning, tokenization and structural extraction.

  2. Model Selection & Fine-Tuning

    I worked with a Transformer-based architecture and fine-tuned RoBERTa to capture the semantic structure of CVs and improve the analysis of candidate information.

  3. Feedback Generation

    I developed a module that transforms the model predictions into clear and actionable recommendations for candidates.

📊 3. Results & Performance

93.48%

Model Accuracy

Best reported performance of the NLP module developed for the platform.

The module provides real-time CV analysis through the React interface and helps candidates improve their CV before applying for jobs.
